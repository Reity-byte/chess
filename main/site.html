Under the hood

A real search engine, in plain JavaScript

Fast search board

A compact 0x88 typed-array board with integer moves and incremental Zobrist hashing — no allocations in the hot path.

Principal variation search

Alpha-beta with PVS, null-move pruning, late move reductions, check extensions and mate-distance pruning.

Tactics-aware quiescence

Captures are resolved past the horizon; static exchange evaluation skips losing ones and orders the rest.

Persistent transposition table

A typed-array hash table that survives between moves, so every search starts with what the last one learned.

Never freezes the page

The engine and the game review run in Web Workers — clocks tick and pieces animate while it thinks.

Honest game review

Each position is searched once with multi-PV, scoring the played move in the same search as the best one.

  • Castling, en passant and every promotion
  • Check, checkmate and stalemate
  • Threefold repetition, 50-move rule, insufficient material
  • PGN import and export
Built with vanilla JavaScript — no frameworks, no backend.
